📝 To-Do List Application using Stack (C++)

This is a console-based To-Do List application built using the Stack data structure in C++. The project allows users to add, view, and remove tasks in LIFO (Last-In-First-Out) order, demonstrating how stack operations can be applied in a real-world scenario. It provides a simple interface to manage tasks and reinforces understanding of stack behavior using standard C++ concepts.

🚀 Features

➕ Push tasks onto the stack

👀 View all tasks currently in the stack

❌ Pop/Delete the most recent task

📂 Tasks stored in memory during runtime

🔁 Fast and simple stack-driven workflow

💡 Demonstrates stack operations clearly

🎯 Learning Objectives

This project is built to strengthen knowledge of:

Stack Data Structure & LIFO concept

Array / STL stack implementation

Functions & modular C++ programming

Loops, conditionals & input handling

Problem-solving using data structure logic
